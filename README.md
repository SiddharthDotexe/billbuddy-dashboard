# BillBuddy Dashboard

Create the frontend for a SaaS product called BillBuddy, an invoice and payment tracker for freelancers in India and internationally.

For this first step, build ONLY the dashboard interface. Do not add authentication, database integration, payment processing, or email functionality yet.

Design requirements:

Professional, modern SaaS dashboard.

White or light background, dark readable text, and a restrained blue accent.

Responsive layout for desktop and mobile.

Sidebar navigation: Dashboard, Invoices, Customers, Settings.

Top bar with the BillBuddy logo, search field, and profile placeholder.

Four summary cards: Total Invoiced, Paid, Pending, and Overdue.

A recent invoices table with invoice number, client, date, amount, and status.

A prominent "Create Invoice" button.

Realistic sample data clearly treated as demo data.

Clean spacing, accessible contrast, and consistent typography.

Use React and TypeScript. Keep components organized and reusable. Use mock data only for this prototype. Do not imply that any real invoices or payments have been created.

At the end, explain which files you created and how I can preview and test the dashboard.
